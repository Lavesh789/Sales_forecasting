Hyperparameter Tuning

RandomizedSearchCV over XGBoost found best params n_estimators=300, max_depth=9, learning_rate=0.01, subsample=0.8, giving MAE 4.09 / RMSE 5.40 / R² 0.9663 on the held-out test set — close to, but slightly below, the untuned XGBoost run above (0.9715). This is a normal outcome of cross-validated search: the tuned params optimize average CV performance across folds, not this single train/test split.
